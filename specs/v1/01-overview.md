# 1. Overview

## Purpose

The Agentic Trust Protocol defines an interoperable model for identity, delegated authority, authorization, capabilities, policy, trust, verification, revocation, provenance, and accountability in agentic systems.

## Core model

```text
Principal → Delegation → Agent → Authorization → Action
```

The protocol separates authority decisions from domain-specific execution.

## Scope

Version 1 focuses on the minimum trust lifecycle required to authorize agent actions:

- Identity
- Credentials
- Delegation
- Authorization
- Capability
- Policy
- Trust
- Consent
- Revocation
- Provenance
- Audit
- Human approval

## Out of scope

Payment execution, wallets, settlement, refunds, and financial ledgers are outside the Foundation protocol and belong to Agent-Pay or other domain-specific execution systems.
