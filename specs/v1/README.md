# Agentic Trust Protocol v1

Version 1 defines the initial protocol scope for agent identity, delegated authority, authorization, capabilities, policy, verification, revocation, and auditability.

20. Conformance

These files will become normative specifications as each area is finalized. The current repository stage establishes the structure without prematurely freezing protocol details.
