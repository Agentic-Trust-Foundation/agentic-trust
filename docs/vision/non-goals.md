# Non-Goals

Agentic Trust Foundation deliberately does not aim to become:

- A payment processor
- A wallet provider
- A bank-account system
- A virtual-card issuer
- A merchant settlement system
- A financial ledger
- A general replacement for enterprise IAM
- A healthcare IAM system
- A cloud IAM system
- A centralized global trust authority
- A mandatory identity provider
- A blockchain requirement
- A cryptocurrency requirement
- A mandatory agent implementation
- A mandatory cloud provider

Domain-specific execution systems may integrate with the Foundation through open protocols.
